See the **"Record Your Own Walkthrough"** section in [`docs/DEMO.md`](../DEMO.md)
for recommended tools and a step-by-step recording script.

> Tip: keep GIFs under ~10 MB so they render inline on GitHub. Use
> [HandBrake](https://handbrake.fr/) to compress larger MP4 recordings.
